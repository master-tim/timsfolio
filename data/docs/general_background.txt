## Software Engineering Experience

Most of my professional work has been at **Redbrick** in Seoul.

**AI Engineer (Jul 2024 – Present):**
- Designed and built an end-to-end AI game creation system that takes natural language prompts and produces playable 3D games — covering intent parsing, asset generation, scene composition, and game logic synthesis.
- Built production RAG pipelines (LangChain, Vercel AI SDK) over 15K+ documents in ChromaDB using hybrid retrieval, query rewriting, and re-ranking.
- Implemented multi-step agentic workflows (chain-of-thought, ReACT) to orchestrate LLM calls across asset generation, physics configuration, and script authoring — handling up to 8 dependent tool calls per request.
- Designed semantic caching layers (embedding similarity-based lookup), reducing redundant LLM calls by ~40%.
- Owned model evaluation and safety: built prompt regression harnesses, implemented output guardrails (content filtering, structured validation), and enforced policy-compliant generation across all production endpoints.

**3D Frontend Engineer (Jul 2023 – Jul 2024):**
- Developed and scaled a browser-based 3D game engine (Three.js, WebGL, TypeScript) powering a platform with 54M+ game plays and 10M+ user sign-ups.
- Led codebase modernization of 50K+ lines from Webpack to Vite, upgraded the Three.js rendering pipeline, and replaced the physics engine — reducing build times by ~60%, shrinking production bundles by ~35%, and cutting hot-reload time from 8s to under 1s.
- Refactored the engine into modular, testable packages to unblock parallel development across 3 teams.
- Redesigned the onboarding flow using session replay analysis and user interviews, increasing 7-day activation by ~25% and Day-30 retention by ~15%.

Earlier in my career, I worked on **embedded systems and robotics** at DECS Lab, UNIST (Feb 2021 – Feb 2023). I wrote IoT firmware in C for ARM Cortex-M MCUs powering real-time smart sensor arrays (50+ devices, sub-ms latency requirements). I also designed expressive robotic faces and mentored design students in coding and prototyping.
